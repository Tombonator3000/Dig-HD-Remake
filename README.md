# spilldata

Denne grenen inneholder bare spillfilene til The Dig (engelsk standardutgave, data fra november 1995) som HD-prosjektet trenger: `DIG.LA0`, `DIG.LA1` og `VIDEO/`.

Musikk og tale (`DIGMUSIC.BUN`, `DIGVOICE.BUN`) er over GitHubs grense på 100 MB per fil og ligger bare på Google Drive.

Grenen er privat bruk. Repoet må holdes privat så lenge denne grenen finnes. Hent dataene inn i `game/` i main med `tools/hent_spilldata.sh`.

Sjekksummer: `game/SHA256SUMS`.
